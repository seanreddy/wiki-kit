Example

Every diagram idiom the wiki draws, once each

This page exists to be copied and then deleted. Each section places one generated diagram, drawn from placeholder data by a small renderer, so you can see the whole repertoire before you write your first page — and lift the idiom you need.

How a diagram gets onto a page

A renderer, a registry entry, one placement

A diagram is a Python function that returns an SVG fragment. It is registered once with a slug, a title and a lede, and placed once from prose with a {{section:slug}} line. Prose cannot carry inline SVG; every drawing goes through a renderer, which is what lets the build check that no colour was typed by hand.

Engineering notes

The renderers live in packs/example_pack.py; the shared drawing helpers in engine/svg.py. tests/test_example_pack.py is the pack-test idiom — copy it with your pack.

Flow

Pipelines, chains and cycles, drawn as boxes

These three idioms all show work moving through a sequence of steps — a straight run, a run with a side path, and a run that loops back on itself.

Pipeline with feedback

Five stages in a row, one return edge

Drawn with svg.frame, svg.rect, svg.arrow and svg.wrap; the return edge is a quadratic path closed by svg.arrowhead.

Stage chain with a bay

A chain, plus a side bay for read-backs

Drawn with svg.frame, svg.rect and svg.arrow -- the bay's two dashed arrows are svg.arrow with dashed=True.

State cycle

Four states, straight and arced transitions

Drawn with svg.frame, svg.rect and svg.arrow for neighbour transitions; the two skip transitions are arced paths closed by svg.arrowhead.

Structure

One centre, two columns, or three inputs

These idioms show shape rather than sequence: how something relates to a centre, splits into two sides, or narrows toward one outcome.

Hub and spoke

One hub, six spokes, fanning outward

Drawn with svg.frame, svg.rect and svg.line -- every spoke is a plain line, not an arrow.

Decision boundary

Two columns, a dashed midline, crossing arrows

Drawn with svg.frame, svg.rect, svg.line (dashed) and svg.arrow for the two crossing edges.

Converging axes

Three inputs converge on one outcome

Drawn with svg.frame, svg.rect and svg.arrow -- three inputs, one shared target point.

Comparison

The same shape, repeated, to show what changed

A reader trusts a comparison more than a claim: a grid of verdicts, a set of identical panels, one scene shown twice, or a set of rungs climbing in order.

Verdict matrix

Rows by columns, each cell a verdict

Drawn with svg.frame, svg.rect and svg.text -- cell fill is svg.chrome's yes/no/quiet roles, cycled by row plus column.

Small multiples

Four panels, same frame, pass or fail

Drawn with svg.frame, svg.rect, svg.text and svg.line -- the check and cross glyphs are both built from two svg.line calls.

Before and after

The same scene twice, one change

Drawn with svg.frame, svg.rect and svg.text -- the same element restyled from a plain fill to the yes role.

Ladder

Five rungs, climbing left to right

Drawn with svg.frame, svg.rect, svg.arrow and a dashed svg.line baseline.

The table above is the idiom itself, stated once, before the three sections below draw it: put the table first when a reader needs the shape before the example.

Numbered pins

Pins on a scene, legend beside

pinlabel
1Marker 1: Input 1
2Marker 2: Input 2
3Marker 3: Input 3
4Marker 4: Outcome

The scene is svg.frame and svg.rect, each pin a numbered marker with svg.text; the legend is svg.table.

Rule box

Ordered logic in a fenced ASCII box

+----------------------------------------+
| RULE 1  IF Condition X                 |
|      THEN Stage A                      |
+----------------------------------------+
| RULE 2  IF Condition Y                 |
|      THEN Stage B                      |
+----------------------------------------+
| RULE 3  IF Condition Z                 |
|      THEN Stage C                      |
+----------------------------------------+
| RULE 4  IF Condition W                 |
|      THEN Stage D                      |
+----------------------------------------+

An ASCII box built from plain string formatting -- no svg helper draws a rule that is read top to bottom, not sighted.

Imagery

Committed pictures, cited by their bare filename

A photograph is never drawn — it is a file, checked into images/, and cited from prose by its bare filename. The renderer below only lays it out; the citation gate is what proves the file exists.
